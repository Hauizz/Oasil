# 本地打开方式

## 一键启动（推荐）

在项目根目录**双击 `启动网站.bat`**，它会自动完成：

1. 找到 Java 17+（系统 `JAVA_HOME` 指向低版本也没关系，脚本会自己找）
2. 代码有改动时自动重新打包（没改动就直接用现成的 `target/*.jar`）
3. 启动服务并等待就绪
4. **自动打开默认浏览器** → http://localhost:8080/

服务在启动窗口里前台运行，日志实时可见。

**停止服务**：关闭该窗口，或按 `Ctrl+C`，或双击 `停止网站.bat`。

## 页面地址

| 页面 | 地址 |
| --- | --- |
| 智能问答（首页） | http://localhost:8080/ |
| 文件仓库 | http://localhost:8080/repository.html |
| 日志统计 | http://localhost:8080/logs.html |

## 为什么不能直接双击 HTML 文件？

`src/main/resources/static/` 下的 HTML 是**页面模板**，由后端服务和接口一起工作。
直接双击打开时是 `file://` 协议，浏览器的安全策略不允许这种页面访问本地后端接口，
所以「文件仓库」「日志统计」「智能问答」的功能都会用不了（打开后页面顶部会自动弹出提示）。

请统一用 `启动网站.bat` 打开，它给你的是同一套页面，只是通过服务地址访问，功能完整。

## AI 问答的 API Key

`application.yml` 中写的是 `${deepseek_api_key}`，二选一配置即可：

1. 设置系统环境变量 `deepseek_api_key`
2. 在项目根目录新建 `deepseek-key.txt`，把 key 粘进去（启动脚本会自动读取并注入）

不配置也能正常使用**文件仓库**和**日志统计**，只有「智能问答」会提示调用失败。

## 命令行方式（可选）

```powershell
.\启动网站.bat                # 默认 8080 端口，自动打开浏览器
.\启动网站.bat -Port 9000     # 使用其它端口
.\启动网站.bat -NoBrowser     # 只启动服务，不打开浏览器
.\停止网站.bat                # 停止服务
.\停止网站.bat -Port 9000     # 停止指定端口上的服务
```

## 文件说明

```
启动网站.bat          一键启动（双击这个）
停止网站.bat          一键停止
scripts/start-site.ps1   启动逻辑（找 Java / 打包 / 启动 / 开浏览器）
scripts/stop-site.ps1    停止逻辑（按端口找 Java 进程并结束）
```
